# 站点图标 API：Java 本机工具与 PHP 独立接口的取舍

> 整理日期：2026-10-24；验证日期：2026-10-23。类型：实现与 HTTP 验证记录。个人实现尚未发布，不提供在线服务或下载入口。

给网站取一张图标看似简单，实际要处理HTML中的多种候选、相对地址、重定向、图片格式、缓存和下载失败。真正影响选型的还有调用者：可信本机工具与匿名公网接口，需要的网络边界差别很大。

本次以 [owen0o0/getFavicon](https://github.com/owen0o0/getFavicon) 为起点，分别实现了Java工具和PHP衍生接口。Java为独立实现，PHP基于上游重构；两版都完成了有限HTTP验证，但不是已经公开托管的成品服务。

## 来源与版本

PHP衍生起点为上游 [dc16836](https://github.com/owen0o0/getFavicon/commit/dc16836ec478b6a115a9c9fded40cbf63fe84580)，版本1.2.1，保留MIT许可与原作者署名。代码许可不转移站点图标和商标的使用权。

Java验证环境为JDK21，使用HttpClient、Jsoup和磁盘缓存；PHP本机验证版本为8.5.8，需要curl、dom、fileinfo。PHP衍生声明支持8.4/8.5，但8.4未完成本机实测，配置的CI也尚未在GitHub执行。部署应重新核对 [PHP支持版本](https://www.php.net/supported-versions.php)及安全补丁，不能将本次版本视为持续有效的部署建议。

## 两种实现的取舍

| 维度 | Java本机工具 | PHP独立接口 |
| --- | --- | --- |
| 输入范围 | 页面地址归一为源站，按协议、主机、端口取图标 | 保留页面路径与查询，适合不同页面有不同图标的站点 |
| 图标候选 | HTML候选、根favicon、可配置第三方兜底、默认图标 | HTML的icon/apple-touch-icon、根favicon、默认图标；不调用第三方图标服务 |
| 图片格式 | 保留识别出的MIME，SVG响应带sandbox限制 | 拒绝SVG，接受已识别的常见栅格图片和ICO |
| 网络边界 | 允许内网，面向可信本机调用者 | 只允许公网HTTP/HTTPS的80/443端口，逐跳校验并绑定已校验DNS地址 |
| 缓存 | 按源站，成功30天、默认结果12小时 | 按完整地址，成功30天、默认结果12小时 |
| 可观察性 | 响应标记缓存命中与默认图标，支持刷新 | 同样标记缓存/默认结果，支持刷新；参数错误返回JSON |

默认图标不代表目标网站获取成功。保留默认结果标记和较短失败缓存，比返回一张看起来正常的图片却无法区分失败更实用。刷新会跳过服务端缓存，公共入口还应限制刷新权限和频率。

Java的第三方兜底会把站点URL发给外部服务，敏感内网站点不宜直接沿用。PHP的公网检查也不等于可以无鉴权上线：限流、并发限制、出站防火墙和磁盘配额仍是托管环境的职责。

## 实际验证了什么

- Java所在工具模块当时185项测试通过，其中图标相关检查覆盖真实本机HTTP请求、重定向循环、体积限制、慢响应、MIME、多候选、缓存和刷新。185是整个模块数量，不是图标专属用例数。
- PHP8.5.8下52项检查通过，覆盖地址策略、真实本机cURL、DNS绑定、解析候选、超时/超限、缓存重建和真实API响应；另完成PHP语法检查。
- 两版均实际获取 [php.net](https://www.php.net/) 的公开图标并验证缓存命中。Java得到SVG，PHP拒绝SVG后取得PNG。

这些证据证明本次有限流程可用，不能推出任意网站、所有DNS环境或公网生产部署可靠。没有完整浏览器验收，也没有完整图像解码、恶意文件或全量安全审计。

## 适合谁，仍有什么限制

已有Java工具平台、只供可信用户调用，可以选择Java思路；需要轻量PHP接口，可参考独立下载与缓存设计。PHP版无需数据库，但当前不解析manifest或JavaScript生成的图标，也不处理登录页面；多个并发请求可能重复抓取，过期缓存按需覆盖，磁盘清理需另行安排。

个人实现目前没有公开仓库或Demo。本篇分享经过验证的实现取舍与边界；可公开获取的源码入口仍是上述原项目，不将其旧版行为等同于本次重构结果。
