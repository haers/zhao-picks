# Zhao Picks · 我的开源精选

记录我亲自用过、觉得不错、愿意推荐的开源项目。

从真实使用出发，写清项目解决什么问题、为什么值得推荐，以及使用中遇到的不足。推荐代表个人体验，适合自己的工具也未必适合所有人。

## 收录原则

- **亲自使用**：至少实际试用过，再决定是否收录。
- **有明确用途**：能解决具体问题，写清适合什么场景。
- **说明推荐理由**：记录自己的判断，不按 Star 数量排名。
- **如实记录不足**：区分官方提供的功能与自己实际验证的体验，不把初次试用写成长期使用。
- **保留来源**：优先链接原项目，个人 Fork 作为整理入口另行标注。
- **持续更新**：记录体验日期和使用状态；停用后保留原因，方便以后回看。

## 健康与休息

### Stretchly

让长时间使用电脑的人记得停下来休息。

| 项目 | 说明 |
| --- | --- |
| 原项目 | [hovancik/stretchly](https://github.com/hovancik/stretchly) |
| 我的 Fork | [haers/zhao-stretchly](https://github.com/haers/zhao-stretchly) |
| 官方网站 | [Stretchly](https://hovancik.net/stretchly) |
| 官方下载 | [上游 Releases](https://github.com/hovancik/stretchly/releases) |
| 支持平台 | macOS、Windows、Linux；具体系统版本要求见上游文档 |
| 上游许可证 | BSD-2-Clause，以原项目许可证为准 |
| 使用状态 | 已试用，初步推荐 |
| 最近体验记录 | 2026-10-21 |

**为什么收录**

我实际用了一下，觉得不错，因此把它作为这份清单的第一个项目。它解决的是长时间使用电脑时容易忘记休息的问题，适合需要此类提醒的人尝试。

**功能参考**

上游文档介绍了短休息和长休息提醒、提醒前通知，以及可调整的休息偏好。这些是官方功能说明，不代表我已经逐项验证。

**体验与不足**

目前是初步试用记录，尚未形成长期使用结论。提醒对工作节奏的影响、常用配置和具体不足，将在后续使用后补充。

**Fork 说明**

`zhao-stretchly` 是我为方便个人整理而保留并重命名的 Fork，目前没有自行修改上游代码的计划。项目由原作者和社区开发维护；使用说明、版本更新和下载优先参考原项目。

## 如何维护这份清单

新项目先加入索引，再按下面的格式补充记录。分类随实际收录内容增加。

```text
项目名称：
一句话用途：
原项目地址：
我的 Fork 地址（可选）：
为什么推荐：
实际使用场景与体验：
已遇到的不足或尚未验证的部分：
使用状态：已试用 / 持续使用 / 已停用
体验日期：YYYY-MM-DD
```

欢迎通过 Issue 推荐项目；经我实际使用并认可后，再加入正式清单。
